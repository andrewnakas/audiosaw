Open-source DAWs in the style of Logic, Ableton, FL Studio and Pro Tools.

In the second half of 2026 a wave of new open-source music studios appeared, each modelled on the workflow of a commercial one and most of them written from scratch in Rust. This page lists the nine we know of, what each is modelled on, who makes it, its licence and how far along it says it is. Two of them compile to WebAssembly and run on this site; the rest are desktop programs you download from their own pages.

SoundCraft

In the style of Pro Tools

Edit and Mix windows, comping playlists, automation modes, surround panning, CLAP plugins. Part of ArtCraft's family of clean-room "Craft apps" in Rust.

Pro Wave

In the style of Logic Pro

Tracks area with MIDI and audio regions, library, inspector, piano roll, mixer and a built-in synth, in Rust with egui. Reads EXS24 and SFZ sampler instruments and has begun reading .logicx project bundles. Plug-in hosting and Live Loops are still on its roadmap.

Suhina

In the style of Ableton Live

Session-style clip launching with quantisation plus a linear arrangement, in Rust. Opens, plays and renders Live Sets (.als) you made yourself, with real-time time-stretching; CLAP and VST3 plug-ins run sandboxed in a separate process.

How to read this list

Everything on a card comes from the project's own repository and README as they stood on 13 November 2026: the description, the licence, the platforms and the status. We have run SoundCraft's and Honeydew's web builds, because those are hosted here and checked before each release of this site. We have not installed or tested the desktop builds of any of the nine, so nothing here is a review, and "status" is the project's own word for itself. Most of these programs are weeks or months old and several call themselves alpha or pre-alpha; expect missing features and file formats that still change.

"In the style of" means the workflow and layout a project says it follows. None of them is made by, or affiliated with, Apple, Ableton, Image-Line, Avid, Bitwig or Reason Studios, and the product names are theirs.

Which one for which habit

If your hands know Pro Tools, with an Edit window and a Mix window and editing by modes, SoundCraft is the one built around that, and it is the furthest along in mixing features on paper. If you write by launching clips in a grid, the Ableton Live way, look at Suhina, which reads Live Sets, at Hikaru OpenLive, which is aimed at live looping on Linux, and at the clip grid inside LYNX SHARE. If you think in patterns, a channel rack and a playlist, the FL Studio way, there are three desktop programs, Lemon Studio, LYNX SHARE and WAVE, plus Honeydew, which follows the mobile app and is the only one of the nine built for touch. Pro Wave is the one for Logic Pro users: a single window with the tracks area, library, inspector and mixer where Logic puts them. And OpenRB-338 is not a general studio but a faithful rebuild of one beloved instrument, the 1997 ReBirth with its two acid bass lines and two drum machines.

What "clean-room" means, and why it matters

Most of these projects describe themselves as clean-room: the people (and, openly, the coding agents) writing the program work from public documentation, their own observation of how the original behaves, and written specifications of file formats, never from the original's code. That is the long-established way to build compatible software without copying it, the way compatible PC BIOSes and office-file readers were made. It is why these programs can open another product's project files and feel familiar without containing anything of the original. Honeydew states that it holds no code, samples, presets or artwork from FL Studio Mobile; Suhina says the same of Ableton's products and reads only Live Sets you made yourself. OpenRB-338 is the exception in method: it was rebuilt from study of the original program to match its output exactly, and it carries the original's drum sounds, which its README says plainly.

Licences differ in what they ask of people who pass the program on. SoundCraft is under Apache 2.0, which permits almost any use. The others use the GPL or the AGPL, which require anyone who distributes a modified version, or in the AGPL's case runs one as a network service, to publish their changes.

Trying one without installing

Two of the nine publish a WebAssembly build, and both run here in a sandboxed frame. Honeydew is a working studio in the tab: add a synth or a drum kit and play. SoundCraft's web build opens a demo session to look around in; it cannot open or save your own files in the browser. The other seven are native programs with real-time audio threads and plugin hosts, which a browser cannot provide, so for those the download links on their own pages are the way in.

If what you need today is simply to edit, mix or convert audio you already have, without learning a studio, the tools on this site do that in the browser: a multitrack editor, a stem splitter, audio to MIDI and the rest are listed on the tools page. And for rebuilt classics rather than studios, see Webamp, the module player and the DX7-style synth.

Where this list comes from

SoundCraft and Honeydew are catalogued on Recomp, a directory of clean-room, decompiled and reimplemented software that records each project's method, licence and whether you need the original; the others were found on GitHub. If you make or know a project that belongs here, tell us through the contact page.

FAQ

Is there an open-source alternative to Ableton Live?

Three new projects follow its clip-launching workflow: Suhina (Rust, GPL, reads Live Sets, pre-alpha), Hikaru OpenLive (Rust, AGPL, Linux) and the clip grid in LYNX SHARE (C++, AGPL). All are young; check each project's own status.

Is there an open-source alternative to Logic Pro?

Pro Wave is an alpha-stage DAW in Rust laid out like Logic Pro, for Windows, macOS and Linux, under the GPL.

Is there an open-source alternative to FL Studio?

Lemon Studio, LYNX SHARE and WAVE follow the desktop program's pattern workflow, and Honeydew follows FL Studio Mobile. Honeydew runs in the browser on this site.

Is there an open-source alternative to Pro Tools?

SoundCraft, from ArtCraft, is a clean-room workstation in Rust with Edit and Mix windows, under the Apache 2.0 licence. Its web build runs a demo session on this site.

Can I run any of these in a browser?

Two: Honeydew, which is a working studio in the tab, and SoundCraft, whose web build opens a demo session. Both are hosted on this site. The others are desktop programs.

Have you tested these programs?

Only the two web builds hosted here. The descriptions of the desktop programs come from their own repositories as of 13 November 2026.
