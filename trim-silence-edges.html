Trim the silence off the ends. Keep the middle untouched.

You hit record, waited 3 seconds, then started talking. Or the voice memo recorded an extra 4 seconds of room tone at the end before you tapped stop. "Top and tail" trimming just snips that — without auto-editing pauses inside the recording. Drop the file, click trim, download the clean version.

When to use this vs other silence tools

  • This page (top & tail) — cuts only the start/end silence. Middle of the file unchanged. Use for voice memos with awkward startup, podcasts with pre-roll gap, samples needing clean attack/release.
  • Silence remover — finds and cuts every silent gap. Use when you want to auto-compress a long recording: lecture, interview, sermon. Removes pauses.
  • Audio cutter — manual: you pick the in/out points. Use when you want exact control or you need to grab a specific section.

How the detection works

We scan from the start of the file forward until we find the first sample whose absolute value exceeds the threshold (e.g., -45 dB = 0.005 in linear amplitude). We back off 200 ms from there — that's the trim point at the start. Then we scan from the end backward to find the last sample above threshold; we add 300 ms after that for the end trim point.

The samples between those two points become the output file. Nothing in the middle is altered.

Good defaults for common recordings

  • iPhone voice memo — −45 dB threshold. The handset mic has very low noise floor.
  • Lapel mic recording — −45 dB. Lavs are clean.
  • Phone speakerphone recording — −35 dB. More room noise.
  • Zoom call recording (computer audio) — −45 dB. Good signal.
  • Field recording with handheld recorder — −35 to −45 dB depending on location.
  • Music sample with clean tail — −55 dB to preserve very quiet decay.

FAQ

What if the file has no silence at the start or end?

We won't trim anything. The output will be the same as the input (just re-encoded if you chose a different format).

Will it cut a quiet intro fade?

Only if the fade goes below the threshold for long enough. If you intended the fade, it'll be trimmed — pick a higher threshold (-55 dB) to preserve quieter content, or use our audio cutter for exact control.

How much silence is "enough" to be trimmed?

Anything below the threshold continuously, from the edge. The first sample above threshold (going inward from either end) is the new boundary.

Will the file length be exact, or rounded?

Trim points are at the sample — about 0.02 ms precision at 44.1 kHz. For all practical purposes, exact.

What if my recording is all silence?

We'll output the file unchanged with a warning. The threshold scan found no audio above the line; we won't truncate to zero length.

Does anything upload?

No. Detection and trimming run in your browser.

What's the difference between this and the silence remover?

Our silence remover cuts ALL silence including pauses inside the recording. This page only trims the silence at the very start and end — so the natural pauses inside a podcast or voice memo stay intact. Use this when you just want clean edges, not auto-editing.

How do I trim the silence at the beginning of a voice memo?

Drop the voice memo here. Set the silence threshold (default -45 dB, fine for most recordings). Click trim. We'll scan in from each end, find the first sample above the threshold, and cut everything before/after. The middle of the recording stays untouched.

What threshold should I use?

-45 dB is a safe default — strict enough to ignore quiet content like room tone or breath, loose enough to catch the very first word. For very quiet recordings, go to -55 dB. For loud recordings with significant background noise, -35 dB.

Will it accidentally cut quiet content like fades or breaths?

Only at the very edges. We add a 200 ms pad before the first detected sound and 300 ms after the last to preserve attack transients and natural decay. You won't lose the first consonant or last breath.

What if the file has long silence in the middle?

This tool ignores middle silence — by design. For an interview with a long awkward pause in the middle that you want to compress, use our auto silence remover or cut manually with the audio cutter.
