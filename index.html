01.Why this site

Most "online audio converter" sites ask you to upload a file you wrote, recorded, or paid for to a server in someone else's country, wait in a queue, and then trust them to delete it. That is silly. Your browser can already decode and encode audio. We wrap Web Audio and a slim FFmpeg-WebAssembly build in a clean drop target, and that is the whole site — there is no upload endpoint to trust, because there is no upload.

Nothing leaves the tab

Open this page, switch off your wifi, then drop a file. It still converts. That is the test, and you can run it right now.

Nothing to install

No download, no signup, no daily quota, no watermark on the way out. You are already where you need to be.

Real controls

Bitrate, sample rate, channel count, LUFS target — actual values you pick, not three presets and a "Pro" wall.

Batch is normal

03.FAQ

Does my audio actually stay on my device?

Yes. Open this page, switch to airplane mode, then drop a file. It still converts. That's the test, and the whole point of the site.

Why does my browser need a moment to "warm up" the first time?

For most conversions we load a small WebAssembly module (around 3 MB) on first use. After that it's cached and instant. Simple MP3 encoding doesn't need it at all.

Which formats can I convert between?

MP3, WAV, M4A, AAC, FLAC, OGG, OPUS, and audio extracted from MP4, MOV, WebM, MKV. Most common pairs go both directions.

What about DRM-protected files like Apple Music or Spotify?

Those are encrypted and we can't decrypt them. That's a feature, not a bug. Use the original app to export, or buy the unprotected version.

How big can the file be?

Around 500 MB is a safe ceiling on a modern laptop. We can sometimes handle more, but past 1 GB the browser starts running out of memory.

Are you keeping any data?

An analytics ping: page views, which tool you used, whether it worked. No audio data, no filenames, no personal identifiers. No ads and no ad network. You can turn the analytics off from the cookie settings link in the footer.

Why is this free?

The work happens on your computer, so there are no servers to pay for — the whole site is static files on a CDN. No accounts, no upsell, no Pro tier, and currently no ads.

Can I batch-convert a folder of files?

Yes. Drop multiple files at once and you get a zip of all the outputs. Online converters that gatekeep batches behind a paywall — we don't do that.

Can I install this as an app?

Yes. In Chrome or Edge there is an install icon in the address bar; on an iPhone use Share → Add to Home Screen. It then opens in its own window and keeps working with no connection at all, because the tools were never talking to a server. On Android you can also share a file straight into it from another app.

Why is a converted MP3 sometimes a different length than the original?

MP3 encodes in frames of 1,152 samples, so the encoder pads the end out to a whole frame — usually a few tens of milliseconds. If you need a sample-exact length, convert to WAV or FLAC instead.

Will it work on my phone?

Yes, just slower because phone CPUs are slower at decoding. iOS has stricter memory caps, so very large files may fail on Safari.
