SoundCraft: an open-source DAW, running in your browser.

SoundCraft is ArtCraft's open-source digital audio workstation, written from scratch in Rust and laid out like the Edit and Mix windows that studio engineers already know. This page runs its official web build, unmodified: press start and it opens its demo session in the tab. It is a way to see and try the program before installing it, not a replacement for the desktop app, and the section below says exactly where the line is.

Best on a computer with a keyboard and a wide window. Click inside the app once so its shortcuts and its sound work.

What SoundCraft is

SoundCraft is one of the "Craft apps" from ArtCraft: a family of open-source programs, each a clean-room rebuild of a professional tool, written in Rust from public documentation rather than from anyone's code. PhotoCraft is the photo editor, FilmCraft the video editor, and SoundCraft the audio workstation, modelled on the two-window workflow of Avid Pro Tools. The source is on GitHub under the Apache 2.0 licence, and the project says openly that much of it is written by coding agents working to a published protocol. It is listed on Recomp, a catalogue of clean-room and reverse-engineered software, with its method and licence.

The project's own feature list for the desktop app is long: an Edit window with Shuffle, Slip, Spot and Grid modes, comping playlists and memory locations; a mixing console with ten inserts and ten sends a track, busses, aux inputs, VCAs and automatic plugin delay compensation; Write, Touch, Latch and Trim automation; built-in EQ, dynamics, reverbs, delays and synthesisers; a piano-roll MIDI editor with a score view; surround panning up to 9.1.6; and hosting for external CLAP plugins. It is version 0.20 and marked "in development", so treat that list as the project's description of where it is going and what is there today, not as something this site has tested.

What the web build does, and does not

Every Craft app compiles to WebAssembly as well as to native code, and each release includes that build as a zip "to host yourself". That is what runs here. The project's hosting notes are direct about its limits: the web build has no recording, no native file dialogs and no control channel, and it opens a synthesised demo session. So in this tab you can see the real interface, move around a nine-track session, open the windows and menus, press play and work the mixer. You cannot import your own audio, record a take or save a project. For any of that, download the desktop app, which is free.

If what you want is to edit your own audio in a browser right now, that is what the AudioSaw editor is for: a multitrack editor with a mixer, effects, MIDI tracks and export, working on your own files. It is a smaller program than a studio workstation, but it opens and saves.

How it runs here

Nothing is downloaded until you press start. The app then loads in a frame that is sandboxed from the rest of this site: it runs on what browsers call an opaque origin, so it cannot read this site's storage or cookies, and this page cannot reach into it. The files are the ones in the project's v0.20.1 release, and their SHA-256 matches the checksum the project publishes. The only thing added is a one-line message from the frame's host page to say the app has started.

It draws with WebGPU when the browser offers it and falls back to WebGL 2 by itself. If the frame stays blank or the picture is wrong, which can happen with a WebGPU driver the app has not met, the "Use WebGL" button reloads it on the older, safer path. Browsers only let a page make sound after a click or a key press, so click inside the app once before pressing play. A phone will load it, but the interface is built for a mouse, a keyboard and a wide screen.

Who makes what

FAQ

Is SoundCraft free?

Yes. It is open source under the Apache 2.0 licence, with free desktop builds for macOS, Windows, Linux and FreeBSD and this WebAssembly build for the browser.

Can I open my own audio files here?

No. The project's web build opens a built-in demo session and has no file dialogs or recording. Use the desktop app for your own sessions, or the AudioSaw editor to edit your own files in the browser.

Is this an official ArtCraft page?

No. AudioSaw hosts the project's published web build, unmodified, under its licence. SoundCraft is made by ArtCraft; this site is not affiliated with it.

Is SoundCraft a copy of Pro Tools?

It is a clean-room program: written from scratch from public documentation, with an Edit and Mix window workflow like the one Pro Tools established. It contains none of Avid's code and is not affiliated with Avid.

Why is the frame blank?

Usually a graphics driver that does not get on with WebGPU. Press "Use WebGL" to reload it on WebGL 2. The first load also takes a while on a slow connection: it is 18 MB.

Why is there no sound?

Browsers block sound until you interact with the page. Click inside the app once, then press play.
