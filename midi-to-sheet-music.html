How a MIDI file becomes a score

A MIDI file is a list of key presses: which key, when it went down, when it came up, and how hard. It has no bar lines, no note values and no idea which hand plays what, so turning it into something a pianist can read means making those decisions. The page reads the file's own timeline in beats, not seconds, so a file that slows down at the end or changes tempo halfway still lines up with its bars. Each note's start and end are then placed on a sixteenth-note grid and written as the plain or dotted values that fit inside the bar, with ties across bar lines and across beats where a long note starts off the beat. Every bar sums exactly, which is what lets MuseScore or Sibelius open the MusicXML without complaint.

The sustain pedal is the classic trap. A pianist holding the pedal lifts their fingers early, and the file records notes that sound for two bars. Written that way, every note would be a tied whole note. The page writes the length the key was held, which is what the player's fingers did and what a printed score shows; the pedal itself is not drawn.

If the file carries a key signature, that is used. Many files from DAWs and keyboards do not, so the page counts how long each pitch class sounds and matches that against the major and minor key profiles used by the site's key finder. A tune and its relative minor share a signature, so even a borderline guess gives the right sharps and flats.

Choosing a layout

A staff for each part is the default when the file has two tracks, which is how most piano pieces exported from notation software are stored: one track per hand. Each hand stays on its own staff even where the hands cross. Piano, split at middle C suits a single-track recording from a keyboard, where nothing says which hand played which note: everything from middle C up goes on the treble staff and everything below on the bass staff. One staff with chords works for a guitar or keyboard part you want to read as a lead sheet, and the tune only keeps the highest note at each moment, which is usually the melody, for a flute, violin or singer to read. With more than two tracks, pick a single part from the Part menu, for instance the melody line of a band arrangement; drum tracks on channel 10 are left out.

For your instrument

"Written for" transposes the score so it reads correctly on a transposing instrument: a B♭ clarinet or trumpet part sits a tone above concert pitch, an alto sax a major sixth, a horn in F a fifth, and guitar is written an octave above where it sounds. The key signature moves with it. Downloaded MusicXML keeps the transposed part, so it opens ready to hand to the player.

What it can't do

Each staff is written as one voice. Where a note is held while others move above it, such as a bass note under a running melody in the same hand, the held note is cut short where the next note starts, so the rhythm reads correctly but the hold is lost; a chord's notes must start together to be drawn as a chord. Triplets and swing are rounded to the nearest sixteenth, so a shuffle comes out as dotted rhythms and a triplet run as uneven sixteenths. A pickup bar is not detected: a piece that starts on the last beat is written with rests before it. Dynamics, pedal marks, articulations and lyrics are not written. For a file recorded live without a click, the bar lines follow the file's tempo, not the player's, so set the tempo in your DAW first or expect the rhythm to look busy. For a full engraving job, download the MusicXML and finish it in MuseScore, which is free.

If you have a recording rather than a MIDI file, the audio to sheet music tool writes out a sung or played melody, and audio to MIDI gives you a note-by-note piano roll to tidy first.

FAQ

How do I convert a MIDI file to sheet music for free?

Drop the .mid file above and press Write it out. The score appears on the page; print it, save it as a PDF from the print dialog, or download MusicXML or a tidied MIDI file. There is no account, no watermark and nothing is uploaded.

How do I turn a MIDI file into a PDF?

Write it out, then press Print or save as PDF and choose Save as PDF in the print dialog. Only the score is printed, not the rest of the page.

Why are both hands on one staff, or the hands mixed up?

A keyboard recording does not say which hand played which note. If the file has one track per hand, choose "Two staves, one for each part". If it has one track, "Piano: two staves, split at middle C" puts everything below middle C on the bass staff.

Can I open the result in MuseScore?

Yes. Download MusicXML and open the .musicxml file in MuseScore (File, Open); Sibelius, Finale and Dorico import MusicXML too. The file carries the key, the time signature, the ties and both staves of a piano part.

The rhythm looks wrong. What can I change?

Check the time signature first: a waltz written in 4/4 looks scrambled. Triplets and swing are rounded to sixteenths, and a file recorded without a click has bar lines that do not follow the playing; quantize it in your DAW before converting.

Does it work with drum MIDI files?

No. Channel 10, the General MIDI drum channel, is left out, because drum notation maps each drum to a line on the staff rather than to a pitch. A file with only drums is refused with a message saying so.
