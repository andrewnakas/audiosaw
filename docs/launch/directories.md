# Directory submissions

The least glamorous item in the kit and probably the highest return per minute.
These are aged domains that search engines already trust, several of them give
a followed link, and unlike a launch day they keep sending a trickle for years.

Budget about 90 minutes for the whole list.

## Shared copy

Reuse these everywhere so the entity reads consistently.

**One line (under 100 chars)**

> Free browser-based audio tools — convert, cut, split stems. Files never upload.

**Short (about 250 chars)**

> AudioSaw is a set of 59 audio tools that run entirely in your browser:
> convert between formats, cut and join, normalise to a LUFS target, remove
> noise, split a song into stems with a neural model, and record from a
> microphone. Files never leave your device.

**Long (about 600 chars)**

> AudioSaw does audio conversion and editing entirely inside the browser tab.
> There is no server to upload to — the site is static files, and the Web Audio
> API plus a WebAssembly build of FFmpeg do the work on your own machine. That
> means no signup, no queue, no file-size gate behind a paywall, no watermark
> and no ads, and it keeps working with the network disconnected.
>
> Beyond format conversion it includes neural stem separation (MDX-Net running
> locally), ITU-R BS.1770-4 loudness normalisation validated against FFmpeg's
> reference implementation, PSOLA autotune, monophonic audio-to-MIDI, tempo
> detection, spectral noise reduction and a microphone recorder.
>
> Free and open source under AGPL-3.0.

## The list, in order of value

### 1. AlternativeTo — alternativeto.net
The highest-value one. People arrive there already looking to replace
something, which is the exact moment this wins. List AudioSaw as an
alternative to each of these, since each is a different audience:

| List against | Because |
|---|---|
| Lalal.ai, Vocalremover.org, Moises | stem separation, but those upload and charge |
| Online-Audio-Converter.com, CloudConvert, Zamzar | conversion, but those upload |
| Audacity | far less capable, but nothing to install |
| Media.io, Clideo, Kapwing | same jobs, but no watermark and no account |

Submit once, then add the alternative relationships individually — that is
where the traffic actually comes from.

### 2. Your own GitHub topics
Free, immediate, and how other developers find it. Add to the repo:
`audio`, `audio-converter`, `webaudio`, `webassembly`, `ffmpeg-wasm`,
`stem-separation`, `onnxruntime-web`, `privacy`, `offline-first`, `no-backend`.
Set the repo's website field to `https://audiosaw.com`.

### 3. SaaSHub — saashub.com
Straightforward submission, decent domain, indexes quickly.

### 4. Slant — slant.co
Answer-shaped rather than listing-shaped. Add AudioSaw as an option under
existing questions like "What are the best online audio converters?" with a
real pros-and-cons answer, not a pitch. Write the cons honestly — Slant readers
downvote marketing, and the honest version performs better anyway.

### 5. Futurepedia / There's An AI For That — AI tool directories
The stem splitter and the autotune qualify, so lead with those rather than
with conversion. Several of these have a paid fast track; the free queue is
fine, there is no deadline.

### 6. Awesome lists on GitHub
Search for `awesome-privacy`, `awesome-audio`, `awesome-webassembly`,
`awesome-selfhosted` (it fits the spirit: no server at all). A pull request
with one line in the right section is usually accepted if the project is real.
Read each list's contribution rules first; a sloppy PR to an awesome list is
remembered.

### 7. Privacy-focused communities
PrivacyTools-style listings and r/privacy's sidebar resources. "Processes your
files locally and has no backend" is a genuinely strong claim in that context —
it is the only claim most tools in this category cannot make.

## What not to do

Skip anything that asks for payment for a "featured" slot, anything calling
itself an SEO directory, and any list of 500 sites promising instant backlinks.
Those links are worthless at best and a liability at worst. The list above is
short on purpose.
